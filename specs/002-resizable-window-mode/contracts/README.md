# Contracts: Resizable Window Mode

Normative for `/speckit.tasks` and implementation. `core/` contracts from
`001` are unchanged and still binding.

- `viewport-contract.md` — uniform scale/offset formulas, inverse mapping,
  letterbox rule, mid-stroke resampling rule.
- `window-state-contract.md` — QSettings keys, defaults, save/restore
  lifecycle, F11/toggle behavior.
- `text-fit-contract.md` — wrap rule, creation-time rejection message,
  post-resize clip rule.
- `chrome-layout-contract.md` — layout order, 48px minima, 4.5:1 contrast
  palette, dialog-centering rule.
